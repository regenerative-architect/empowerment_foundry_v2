# v3 test report · scope and known limitations

Run: `python3 scripts/run_tests.py`. The included Playwright integration suite runs rendered standalone HTML using Chromium's `set_content`, because administrative policy in the tool container rejects both direct `file://` navigation and localhost HTTP navigation. This environment also disables IndexedDB/localStorage under `set_content`, so these tests exercised in-memory fallback rather than persistence across browser process restarts.

Checked interactively: 20 registered routes and loaded extension modules, source project creation with HTML injection text, v2 method dependency audit and consent, standalone child generation with proper HTML escaping, child ZIP with optional PWA and per-file byte-check verification if SHA is available, original electricity model, seven-stage fieldwork, saved genome and appended experiment, ten-stage prompt generation and downloadable JSON, opt-in child ZIP with genome and prompts but no observations or owner/project identifiers, private `/2` JSON with original specialized records, actual imports of distinct `/1` Unified and `/1` Ecosystem backups retaining both specialized layers, orphan rejection without altering state, and both unmodified older releases refusing `/2` backup imports.

Checked structurally: 60 method/15 domain/63 technology bank, 22 Protocol reference records and 20 modules; JavaScript syntax checks; contents and SHA-256 checks for packaged output; hosted worker only precaches declared same-origin assets.

**Not tested in this environment:** complete hosted service-worker installation and offline reload, mobile browser matrix, IndexedDB persistence across reload, professional security audit, independent full accessibility/WCAG 2.2 AA audit, correctness or live freshness of each cited research source, downstream user outcomes, and actual external AI inference. An optional `tests/test_hosted_offline_v3.py` attempts live localhost installation where policies allow; it should be interpreted as skipped when `ERR_BLOCKED_BY_ADMINISTRATOR` occurs, not a pass. Do not claim deployment readiness or certification solely from this report.
