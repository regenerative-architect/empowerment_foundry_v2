# Exact capabilities and boundaries

| Component | Concrete implementation | Not implemented or not demonstrated |
|---|---|---|
| Unified research | Ten original Protocol domain engines, curated 22-record bibliography, bounded research prompt bundle with six prompts | No live web search, no recency checks or automatic sources verification |
| Unified scenario | Food mass-to-serving equivalents, electrical duration, repair price difference, conservative plant survival | No calibrated forecasts, safety sign-off, nutritional equivalence or causal inference |
| Unified action | Project-bound seven-stage checklists, observations and source-specific legacy migration | Checklist completion is not outcome measurement |
| v2 ecosystem | Twenty inert declarative module specs, import validator, dependency graph, two child formats, audited ZIP | No arbitrary executable plugin loader, automated agent, server or app store |
| v3 innovation | Editable/forkable genome records with mechanisms, metrics, falsifiers, stop rules, consent, alternatives and locally append-only experiment log | No public registry, real-time multiplayer, verified peer consensus, patent verification |
| v3 prompt studio | Eight entity roles and distinct sub-entities, five- and ten-stage workflows, review gates, expected outputs, generated follow-on questions, Markdown + JSON | No autonomous completion or provider-specific model connection |
| v3 peer exchange | Reviewed, locally validated genome packs; remove projectId/owner on peer export; skip ID collisions and associated observations on import | Free text is NOT anonymized or independently authenticated |
| v3 optional ZIP add-ons | Explicit opt-in genome and one ten-stage chain tied to selected project, experiment observations omitted | Add-ons not embedded in the single-file child output |
| v3 compatibility | Accept old `/1` sources; produce `/2`; stage+validate merges; old readers reject `/2` | Automated semantic reconciliation of different project IDs intentionally not attempted |
| Software assurance | Browser integration, Python static/hash checks, Node syntax checks, optional hosted test script | No external browser acceptance, penetration test, WCAG audit, independent release attestation |

## Advanced, intentionally excluded features

Opt-in WebLLM and model weights (large separate downloads, device-capability and privacy consent needed); autonomous research (requires trustworthy retrieval, source freshness, tool sandbox and cost controls); auto-execution and deployment (requires per-action permissions, rollback and authorization); actual multiplayer or peer federation (requires identity, encryption, conflict resolution, abuse controls); cryptographic signatures and trusted timestamp anchoring (require independently held keys/trust services). None are silently simulated or advertised as present.
